# Simple Modular TCP Server

A modular, high-performance TCP server built from scratch in **C++** and **Qt**. 

## 🎯 About the Project
This project was created for **educational purposes** to dive deep into network programming, clean architecture, and defensive C++ design. The goal is to keep things simple, avoid unnecessary over-engineering (`std::variant` when not needed, minimal abstractions), and build a solid foundation.

* **Language:** C++
* **Framework:** Qt (Core, Network)
* **License:** Fully Open-Source

## 🤖 AI Disclosure
Parts of this codebase may contain minor traces of AI assistance (for brainstorming or debugging), but the vast majority of the code is written and structured by the author to practice, learn, and master modern C++.

## 🚀 Status
Active development. Focused on clean packet routing, protocol design (`Type-Length-Value` pattern), and reliable TCP stream handling.g
